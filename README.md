# SEG_Instance_Transformer_Mask2Former

**Mask2Former - instance segmentation (Transformer) - training and test evaluation**

Part of the *Physical AI Segmentation* reference series of the **Statera Working Group**:
one model per repository, the same data, protocol and metrics for every model - only the model differs.
The data are the FashionLetters36 images of the *Physical AI Object Detection* series (`OD_Image_*`) with masks,
so the results are directly comparable with the detection results.

## Model

- Paper: Cheng, Misra, Schwing, Kirillov & Girdhar, *Masked-attention Mask Transformer for Universal Image Segmentation*, CVPR 2022 (arXiv:2112.01527)
- Implementation source: facebookresearch/Mask2Former maskformer2_R50_bs16_50ep (instance), rewritten line by line; MSDeformAttn encoder = official Deformable-DETR code
- Parameters: 44.01 M (36 classes)

- ResNet-50; MSDeformAttn pixel decoder (6 layers) -> per-pixel embeddings at stride 4
- Masked-attention decoder: 9 layers, 100 queries, round-robin over res5 / res4 / res3
- No box head (box = tight box of the mask)

Loss / assignment: Hungarian matching on 12,544 sampled points; CE (no-object 0.1) x 2 + mask BCE x 5 + dice x 5, deep supervision

Differences from the original (common protocol):

- No ImageNet weights, trainable BN + PreciseBN on the backbone, common init of Conv2d / BN (transformer layers keep xavier), fixed 608 input without padding masks
- Adam 1e-4 for all parameters (official AdamW 1e-4, backbone x 0.1, weight decay 0.05); official gradient clipping 0.01 kept; 30 epochs instead of 50
- Common post-processing (class x mask score, top-300, class-wise NMS 0.5, max 100) instead of top-100 without NMS
- Still improving at epoch 30 (test mask AP50 every 5 epochs below): 30 epochs from scratch is short for this family

## Data: FL36-Seg (synthetic, generated by step 1)

FashionLetters36 regenerated with the same seed plus masks: 36 classes = Fashion-MNIST (10) + EMNIST letters (26);
608 x 608 canvases with 3-10 non-overlapping objects of 32-160 px; 4,096 train / 1,024 test images, fixed seed -
every user generates the same dataset, and images and boxes are identical to FashionLetters36. A mask is the glyph
pixels brighter than 30, the same threshold that defines the boxes. Instance masks: SegmentationObject PNGs (value k = k-th XML object); boxes = tight boxes of the masks.

EMNIST is downloaded from NIST; if the download is refused, fetch `gzip.zip` in a browser from
https://www.nist.gov/itl/products-and-services/emnist-dataset and run
`python data_processing_fl36seg.py --emnist-zip <path>/gzip.zip`.

## Results

Test set: FL36-Seg test (1,024 images, 6,699 objects, 36 classes), after 30 epochs (5.9 h on an RTX 4070 Laptop GPU).

| | AP50 | AP75 | **AP50:95** | Recall (IoU 0.5) |
| --- | --- | --- | --- | --- |
| mask | 0.8243 | 0.7454 | **0.6331** | 0.944 |
| box | 0.7538 | 0.7380 | 0.6435 | 0.899 |

The comparison metric of the series is **mask AP50:95** (mean over IoU 0.50, 0.55, ..., 0.95): on FL36-Seg every correct box is also a correct mask at IoU 0.5, so AP50 saturates.
Semantic mIoU derived from the instances (score >= 0.5, incl. background): 0.6668. Inference: 12.6 images / s incl. post-processing and mask decoding.

Convergence (test AP50 every 5 epochs):

| Epoch | 5 | 10 | 15 | 20 | 25 | 30 |
| --- | --- | --- | --- | --- | --- | --- |
| mask AP50 | 0.006 | 0.202 | 0.593 | 0.716 | 0.796 | 0.824 |
| box AP50 | 0.005 | 0.141 | 0.486 | 0.579 | 0.700 | 0.754 |

Protocol: 30 epochs, Adam lr 1e-4 (constant), effective batch 8 (micro batch 2 x 4 accumulation), input 608, seed 777,
no pretraining; augmentation: horizontal flip + the basic YOLO-paper augmentation (random scale / translation 20 %,
HSV hue 0.1, saturation / exposure 1.5); test evaluation every 5 epochs.

## Usage

```bash
pip install -r requirements.txt
python data_processing_fl36seg.py           # downloads Fashion-MNIST + EMNIST, generates FL36-Seg
python train_seg_mask2former.py               # training, then test evaluation (runs/seg_mask2former/)
python evaluate_seg_mask2former.py            # test evaluation of runs/seg_mask2former/checkpoints/ (or --weights <file>)
```

Data are expected under `$PHYSICAL_AI_ROOT/datasets` (default `~/Physical_AI/datasets`).
Smoke test: `python train_seg_mask2former.py --epochs 1 --max-train 8 --max-test 4`.

Trained weights: the GitHub Release of this repository contains `seg_mask2former_fl36seg_e030.pth` (the run reported above).
Put it into `runs/seg_mask2former/checkpoints/` or pass `--weights <file>` to the evaluation script.
Demo scripts using these weights will be added in a later release.
